# Chinook Salmon Run Reconstruction Application

**Streamlining a Data Science Workflow for Fisheries Management**

[**View the Project Showcase →**](https://clr-saunders.github.io/capstone_project_chinook_app_showcase/)

## About the Project

This project was completed as a **team capstone project** for the **UBC Master of Data Science program** in collaboration with **Fisheries and Oceans Canada (DFO)**.

Our team — **Nicole Link, Michael Oyatsi, and Claire Saunders** — developed an interactive **R Shiny application** to support the exploration, analysis, and reporting of Chinook salmon data used for annual fisheries reporting.

The application brings together biological data processing, data pipeline automation, interactive visualization, and data infilling into a single workflow.

The application and supporting workflows were handed off to DFO at the completion of the project. The production application and full source code are maintained in a private repository due to the project's use of government data and infrastructure.

## Key Features

* Automated biological data processing and data pipeline updates
* Interactive exploration of catch and biological sampling data
* Multi-year and pooled-year analysis
* Age and stock distribution visualization
* Interactive data infilling and reconstruction workflow
* Downloadable tables and outputs
